# UX & Design

## Direction
Simple, modern, trustworthy, mobile-first. The interface should feel current without decorative complexity that hurts speed.

## Core restaurant journey
Search/near me -> results -> restaurant details -> useful action (directions/phone/outbound site) -> review/comment where relevant.

## Principles
- Clear hierarchy and readable typography.
- Large, obvious touch targets.
- Semantic HTML and keyboard accessibility.
- Filters understandable on mobile.
- Avoid carousels/sliders unless a measured user need exists.
- Consistent card/button/form patterns.
- Skeletons/spinners only when truly asynchronous; server-render content whenever possible.
- Sponsored content visually integrated but unmistakably labeled.
