# Native Advertising / Sponsorship

## Goal
Replace current ad-heavy presentation with a clean design. Future monetization is direct sale of restaurant/advertiser placements.

## Rules
- No empty ad holes when no campaign is active.
- Sponsored results/blocks clearly labeled.
- No unexpected layout shift.
- Prefer server-rendered native placements; avoid heavy ad-tech scripts.
- Target by placement and relevant dimensions such as city/category when configured.
- Aggregate impressions/clicks rather than retaining excessive event-level user data.
